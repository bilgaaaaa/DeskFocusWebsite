# DeskFocus Website

DeskFocus is now sold together with PaceTasks, and its website is part of the PaceTasks one:
**https://bilgaaaaa.github.io/pacetasks/** (source in [`bilgaaaaa/pacetasks`](https://github.com/bilgaaaaa/pacetasks), folder `docs/`).

This repository only keeps the old address working. `index.html` sends visitors to the new site, and old section
links such as `#download` or `#faq` land on the matching section there. The app itself is
[`bilgaaaaa/deskfocus`](https://github.com/bilgaaaaa/deskfocus).

GitHub Pages: Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)`.
